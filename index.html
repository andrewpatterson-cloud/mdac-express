Privacy

All profile data is stored in this browser’s Local Storage on this device. There is no backend and no account.

How to use

  1. Create or select a traveller profile.
  2. Choose a trip preset and enter transport details.
  3. Tap Copy payload.
  4. Open the official MDAC form in Safari.
  5. Tap Share → Fill MDAC.
  6. Review, solve CAPTCHA manually, submit.

Shortcut JavaScript

Open autofill-shortcut.js in this repository and paste it into the iPhone Shortcuts “Run JavaScript on Web Page” action.
